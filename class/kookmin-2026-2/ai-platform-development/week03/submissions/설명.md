## 1. 에이전트

- 사용 에이전트: **행사 관리** (사용자가 만든 에이전트, SOURCE `kirocrew`)
- 엔진(KIRO_AGENT): `kirocrew` / WORKSPACE·MEMORY_STORE: `default`
- 프로젝트 폴더(`.kiro/agents/`)에는 정의 파일이 없고, 전역 에이전트 목록(`kirocrew agent list`)에 등록되어 있음.
- 역할 분담: 에이전트(사람 대신)는 규칙 해석과 애매한 값 질문, Python 스크립트는 확인한 규칙으로 항상 같은 구조의 JSON을 검사·저장.

  - 제출용 사본: `submissions/skills/event-prep/`(SKILL.md + scripts/summarize.py) — README 규칙에 따라 레포에 남긴 사본 위치

## 3. 정리(집계) 기준

행사안내(`mission/행사안내.md`) 규칙을 그대로 적용한다.

- 참가 여부가 **참가**인 사람만 인원에 포함. **불참**은 인원에서 제외.
- 불참자는 간식을 선택했더라도 주문 수량에서 제외.
- 간식은 참가자만 집계. 선택 간식은 1인 1개, **받지 않음**은 주문하지 않음.
- 참가자의 간식 선택이 **빈칸**이면 미응답 → 임의로 정하지 않고 `확인할_사람`에 남김.
- 불참자의 빈칸은 확인하지 않음.
- 생수는 간식과 무관하게 참가 인원수만큼.
- 참가 인원이 정원(12명)을 넘으면 `정원_초과`를 참으로 표시.
- 규칙에 없는 값이거나 애매하면 추측하지 않고 `확인할_사람`에 사유와 함께 남김.

### 고정 JSON 항목 (항상 동일한 이름·개수·자료형)

| 항목 | 자료형 |
|---|---|
| 행사명 | 문자열 또는 null |
| 참가_인원 | 정수 |
| 정원 | 정수 또는 null |
| 정원_초과 | 불리언 |
| 간식_주문 | 객체 `{"샌드위치": 정수, "주먹밥": 정수}` |
| 생수 | 정수 |
| 확인할_사람 | 객체 목록 `{"신청번호","이름","사유"}` (빈 목록은 `[]`) |
| 주문_확정_여부 | 불리언 (기본 false) |

- `주문_확정_여부`는 수량 확정 여부이며 실제 주문·예약 완료를 뜻하지 않음(두 상태를 구분).
- 스크립트는 스키마를 만족할 때만 저장하고, 항목 누락·추가나 자료형 오류가 있으면 저장하지 않고 사유를 알림.

## 4. 테스트 후 수정한 점

이번 작업에서 스킬을 실제로 실행·검증하며 고친 내용.

1. **스크립트 신설**: `check-list` 폴더에 `SKILL.md`만 있고 `scripts/summarize.py`가 없었음 → 지침의 집계 규칙·고정 스키마 그대로 스크립트를 새로 작성. CSV 인자/표준입력(`-`) 모두 지원.
2. **BOM 처리**: `참가신청 copy.csv`(변경본) 첫 헤더에 BOM이 있어 `encoding="utf-8-sig"`로 읽도록 해 헤더 검사(`신청번호,이름,학년,참가 여부,간식 선택`)가 통과되게 함.
3. **미응답 vs 불참 빈칸 구분**: 빈칸이라도 **참가자만** 미응답으로 `확인할_사람`에 남기고, 불참자의 빈칸(A10)은 확인 대상에서 제외하도록 분기.
4. **불참자 간식 무시**: 불참자가 간식을 골랐어도(A06 원본의 샌드위치) 주문 수량에 넣지 않도록 처리.
5. **스키마 검사 후에만 저장**: 항목 이름/개수/자료형, 간식 키 집합, `확인할_사람` 객체 키를 검사해 통과할 때만 JSON 저장, 실패 시 사유 출력·미저장.
6. **저장 위치 교정**: 결과 JSON을 스킬 폴더가 아닌 프로젝트 `submissions/`에 저장(`행사준비.json`, `행사준비-변경후.json`).

### 실제 실행·대조 결과

- **원본 `참가신청.csv`** → `submissions/행사준비.json`: 참가 10, 샌드위치 4·주먹밥 4, 생수 10, 확인할 사람 A07, 미확정.
- **`참가신청 copy.csv`(변경본)** → `submissions/행사준비-변경후.json`: A06 불참→참가 반영으로 참가 11, 샌드위치 5·주먹밥 4, 생수 11, 확인할 사람 A07, 미확정.
- 두 실행 모두 스키마 검사 통과(종료 코드 0), 값은 CSV와 직접 대조해 일치 확인.
