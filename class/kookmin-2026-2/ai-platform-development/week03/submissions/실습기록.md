## 2. UI에서 만든 스킬 확인과 수정

- 반복하기로 정한 일과 그 이유: 손글씨 준비 메모를 매번 같은 5개 항목의 JSON으로 정리 — 진행 상황을 일관되게 비교·인계하기 위해
- UI에서 MD 지침을 만들 때 전달한 요구: 메모 날짜/끝낸 일/남은 일/변경한 내용/확인할 질문 5항목 고정, 취소선·X·밑줄·화살표·체크 해석, 애매하면 질문
- 기존 발표 준비 세션에서 가장 먼저 확인한 스킬 이름·SKILL.md 경로·내용: `memo-to-json`, `~/.kiro/crew/skills/memo-to-json/SKILL.md` (당시 SKILL.md만 있고 scripts 없음)
- 해당 스킬의 scripts 폴더에 추가한 Python 파일: `scripts/save_memo.py` (표준 라이브러리만, Python 3.9+)
- SKILL.md에 보완한 실행 절차: 판독 규칙, JSON 항목표(자료형 고정), `save_memo.py` 실행법(파일/stdin), 예시
- 지침에서 내 기준을 확인한 문장: "매번 같은 항목 이름을 사용하는 JSON으로 출력한다", "추측하지 말고 확인할 질문에 남긴다"
- 사진 판독을 확인한 내용과 실제 프로그램 실행 기록: `내준비메모.png`(9/16)·`다음메모.png`(9/20)를 AI가 판독 → `save_memo.py`로 검사·저장, 두 건 모두 종료 코드 0
- JSON 구조 검사에서 확인한 것: 메모 날짜는 YYYY-MM-DD 또는 null, 나머지는 문자열 목록, 빈 목록은 [], 항목 누락·추가/자료형 오류 시 저장 안 함
- 사진과 직접 대조한 판독 내용: 체크 2개·취소선·화살표·파란 수정 글씨·동그라미 강조를 각 항목에 정확히 반영
- 고친 점과 다시 확인한 내용: 제출물 형식 질문을 해결(HTML) 후 재저장, 결과 저장 위치를 scripts→submissions로 교정
