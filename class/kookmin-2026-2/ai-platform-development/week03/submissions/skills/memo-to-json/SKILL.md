# 메모 사진 정리

사용자가 제공한 메모 사진을 읽고 다음 항목으로 정리한다.

- 메모 날짜
- 끝낸 일
- 남은 일
- 변경한 내용
- 확인할 질문

매번 같은 항목 이름을 사용하는 JSON으로 출력한다.

## 판독 규칙

취소선·X 표시·밑줄·화살표·체크표시를 주변 문맥과 함께 읽는다.

- 취소선/X: 취소된 내용. 화살표 뒤에 새 내용이 있으면 "A 취소 -> B" 형태로 `변경한 내용`에 적고, 취소된 값은 남은 일/끝낸 일로 옮기지 않는다.
- 화살표(->): 변경 또는 흐름. 값이 바뀌면 `변경한 내용`에 "이전 -> 이후"로 남긴다.
- 체크표시(✓): 끝난 항목. `끝낸 일`에 넣는다.
- 밑줄·동그라미: 강조. 강조된 내용을 놓치지 않는다.
- 물음표(?)나 "아직/미확정"은 확정이 아니므로 `확인할 질문`에 남기거나 "(미확정)"을 덧붙인다.

읽기 어렵거나 의미가 애매한 부분은 추측하지 말고 `확인할 질문`에 남긴다.

## JSON 항목 (고정)

| 항목 | 자료형 |
|---|---|
| 메모 날짜 | `"YYYY-MM-DD"` 문자열 또는 `null` |
| 끝낸 일 | 문자열 목록 (빈 목록은 `[]`) |
| 남은 일 | 문자열 목록 |
| 변경한 내용 | 문자열 목록 |
| 확인할 질문 | 문자열 목록 |

항목 이름·개수·자료형을 매번 동일하게 유지한다.

## 실행 절차

사진 판독은 AI가 하고, 검사와 저장은 `scripts/save_memo.py`가 한다.
스키마를 만족할 때만 저장하며, 항목 누락·추가나 자료형 오류가 있으면 저장하지 않고 사유를 알린다.

1. 메모 사진을 위 규칙대로 읽어 다섯 항목을 채운 JSON을 만든다.
2. 그 JSON을 파일이나 표준입력으로 검사·저장한다. Python 3.9 이상, 표준 라이브러리만 사용한다.

```bash
cd scripts
# 파일로 검사 후 저장
python3 save_memo.py <입력.json> [출력.json]   # 출력 생략 시 memo.json
# 표준입력으로 검사 후 저장
echo '<json>' | python3 save_memo.py - [출력.json]
```

- 검사 통과: 항목 순서를 고정해 저장하고 종료 코드 `0`.
- 검사 실패: 저장하지 않고 사유를 stderr로 출력, 종료 코드 `1`.

### 예시

`scripts/sample_valid.json`(정상)과 `scripts/sample_invalid.json`(오류)로 확인할 수 있다.

```bash
python3 save_memo.py sample_valid.json out.json    # -> "검사 통과. 저장 완료: out.json"
python3 save_memo.py sample_invalid.json out.json  # -> 저장 안 함, 위반 사유 출력
```

출력 JSON 예:

```json
{
  "메모 날짜": "2026-09-20",
  "끝낸 일": ["원문 확인 끝", "비교표 정리함"],
  "남은 일": ["개선안 그림", "슬라이드 마무리(월 저녁)"],
  "변경한 내용": ["슬라이드 6쪽 -> 4쪽으로 줄이기"],
  "확인할 질문": ["제출 경로 아직 답 못 받음"]
}
```
