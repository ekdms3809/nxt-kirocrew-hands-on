# 참가신청 정리

참가신청 CSV(`신청번호, 이름, 학년, 참가 여부, 간식 선택`)를 읽고 행사안내 규칙대로
준비에 필요한 정보를 정리한다. 신청번호 한 개가 한 사람의 신청이다.

## 집계 규칙

참가 여부와 간식 선택을 함께 읽어 인원과 주문 수량을 계산한다.

- 참가 여부가 **참가**인 사람만 인원에 포함한다. **불참**은 인원에서 뺀다.
- 불참자는 간식을 선택했더라도 주문 수량에서 제외한다.
- 간식은 참가자만 집계한다. 선택한 간식은 1인당 1개로 세고, **받지 않음**은 주문하지 않는다.
- 참가자의 간식 선택이 **빈칸**이면 미응답이다. 임의로 메뉴를 정하지 말고 `확인할_사람`에 남긴다.
- 불참자의 빈칸은 확인하지 않는다.
- 생수는 간식 선택과 관계없이 참가 인원수만큼 준비한다.
- 참가 인원이 정원을 넘으면 `정원_초과`를 참으로 표시한다.

참가 여부가 참가/불참이 아니거나, 간식 선택이 정해진 값(샌드위치/주먹밥/받지 않음/빈칸)이
아니면 추측하지 말고 `확인할_사람`에 사유와 함께 남긴다.

## JSON 항목 (고정)

| 항목 | 자료형 |
|---|---|
| 행사명 | 문자열 또는 `null` |
| 참가_인원 | 정수 |
| 정원 | 정수 또는 `null` |
| 정원_초과 | 불리언 |
| 간식_주문 | 객체 `{"샌드위치": 정수, "주먹밥": 정수}` |
| 생수 | 정수 |
| 확인할_사람 | 객체 목록 `{"신청번호","이름","사유"}` (빈 목록은 `[]`) |
| 주문_확정_여부 | 불리언 (기본 `false`) |

항목 이름·개수·자료형을 매번 동일하게 유지한다.
`주문_확정_여부`는 수량을 확정했는지를 뜻하며, 실제 주문·예약을 마쳤다는 뜻은 아니다.

## 실행 절차

CSV 읽기·규칙 적용·검사·저장은 `scripts/summarize.py`가 한다.
판단(불참 제외, 미응답 분리 등)은 사람이 실수하기 쉬우므로 스크립트가 규칙대로 계산한다.
CSV 헤더나 값이 규칙에 맞지 않으면 저장하지 않고 사유를 알린다.

1. 참가신청 CSV를 준비한다. 헤더는 `신청번호,이름,학년,참가 여부,간식 선택`.
2. 스크립트로 집계·검사·저장한다. Python 3.9 이상, 표준 라이브러리만 사용한다.

```bash
cd scripts
# CSV로 집계 후 저장
python3 summarize.py <입력.csv> [출력.json]           # 출력 생략 시 event.json
# 정원·행사명을 함께 지정
python3 summarize.py <입력.csv> [출력.json] --정원 12 --행사명 "사진동아리 가을 교류회"
# 표준입력으로 집계 후 저장
cat <입력.csv> | python3 summarize.py - [출력.json]
```

- 집계·검사 통과: 항목 순서를 고정해 저장하고 종료 코드 `0`.
- 검사 실패: 저장하지 않고 사유를 stderr로 출력, 종료 코드 `1`.

### 예시

`scripts/sample_input.csv`(정상)로 확인할 수 있다.

```bash
python3 summarize.py sample_input.csv out.json --정원 12 --행사명 "사진동아리 가을 교류회"
# -> "집계 완료. 저장: out.json"
```

출력 JSON 예:

```json
{
  "행사명": "사진동아리 가을 교류회",
  "참가_인원": 10,
  "정원": 12,
  "정원_초과": false,
  "간식_주문": { "샌드위치": 4, "주먹밥": 4 },
  "생수": 10,
  "확인할_사람": [
    { "신청번호": "A07", "이름": "한수빈", "사유": "참가이나 간식 선택 빈칸(미응답)" }
  ],
  "주문_확정_여부": false
}
```
