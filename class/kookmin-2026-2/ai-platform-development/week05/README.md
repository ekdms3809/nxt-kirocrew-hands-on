# 5주차 · 작업 명세와 실행 검증

모든 상황·기관·공지는 수업용 가상 자료입니다. 실제 학교 규정이나 서비스와 무관합니다.

## 자료 안내

Workspace와 터미널의 기준 위치는 `week05`입니다.

```text
week05/
├── 시작하기.html
├── practice/                 # 따라하기 입력·검사기
├── mission/                  # 독립 미션 입력
└── submissions/
    ├── practice/
    │   ├── run01/
    │   ├── run02/
    │   └── boundary/
    └── mission/
```

따라하기에서는 업무 요청의 모호한 기준을 함께 살펴보고, 시작하기 2번의 제공 프롬프트를 입력한 뒤 정제된 명세를 검토합니다. 별도 초안 파일은 작성하지 않습니다. 실행별 결과 폴더와 실행용 명세는 작업 중 생성합니다. 독립 미션에서는 직접 기준을 정하고 명세를 작성합니다.

먼저 [시작하기.html](시작하기.html)을 브라우저로 여세요. 단계별 안내와 복사용 요청, 검증 명령을 함께 볼 수 있습니다.

1. [따라하기: 창고 재고 점검](practice/README.md)에서 작은 작업의 명세를 작성하고 실행 결과를 검사합니다.
2. [독립 미션: 캠퍼스 공지 브리핑](mission/brief.md)에서 같은 과정을 새로운 자료에 적용합니다.
3. [검증 기록 틀](검증기록_틀.md)을 참고해 어떤 조건을 어떻게 확인했는지 남깁니다.

Task Runner의 Workspace와 검사 명령을 실행하는 터미널 위치는 모두 week05 폴더입니다. practice와 mission은 입력 자료 폴더이며, 결과는 같은 수준의 submissions 아래에 작업별로 나눕니다. 별도 worktree에서 실행했다면 실제 저장 경로를 확인하고 검증한 산출물을 제출 위치로 복사하세요.

입력 자료는 보존합니다. 자신이 만드는 명세·코드·결과·검증 기록은 submissions/practice 또는 submissions/mission 안에 둡니다. 실행 전후 결과를 서로 덮어쓰지 않도록 구분하세요. 런타임이 남기는 파일은 별도로 확인합니다.

이 폴더에는 완성된 미션 해답이 없습니다. practice/cases는 검증 수업에서 열어볼 정상·오류 결과 예제입니다.
