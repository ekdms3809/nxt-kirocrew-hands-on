# 창고 재고 집계 및 저재고 판정 보고서

practice/data 의 창고 A·B·C 마크다운 파일을 파싱해 창고별 합계와 품목별 총수량을 집계하고, 품목별 총수량이 5 미만인 저재고 품목을 판정한 결과다.

## 창고별 합계

| 창고 | 합계 |
| --- | --- |
| warehouse-a | 22 |
| warehouse-b | 16 |
| warehouse-c | 16 |
| **전체(grand_total)** | **54** |

## 품목별 총수량

| 품목 | 총수량 |
| --- | --- |
| bottle | 12 |
| cable | 1 |
| hub | 13 |
| mug | 17 |
| sensor | 11 |

## 저재고 목록

판정 기준: 전체 창고 품목별 총수량(`item_total`)이 임계값 `5` 미만(`< 5`)인 품목.

| 품목 | 총수량 | 임계값 |
| --- | --- | --- |
| cable | 1 | 5 |
