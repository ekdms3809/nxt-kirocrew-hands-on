# 데이터 요약 → HTML 보고서

여러 md·csv 파일을 읽고, 요약과 CSV 표를 하나의 HTML 문서로 만든다.
읽기·요약은 AI가 하고, 검사·HTML 렌더·저장은 `scripts/render.py`가 한다.
스키마를 만족할 때만 저장하며, 항목 누락·추가나 자료형 오류가 있으면 저장하지 않고 사유를 알린다.

## 역할 분담

- **AI가 하는 일**: md·csv 파일을 읽고, 아래 스키마대로 요약 JSON을 만든다.
  - md는 핵심 내용을 짧은 문단·불릿으로 요약한다.
  - csv는 그대로 옮기지 말고, 보고서에 담을 **핵심 열·행만** 골라 표로 넣는다.
    행이 많으면 상위 몇 개만 담고, 전체 건수는 `요약` 문장에 적는다.
- **스크립트가 하는 일**: 요약 JSON을 검사하고, 정해진 틀의 HTML로 렌더해 저장한다.
  스크립트는 판단하지 않는다. 요약·선별은 모두 AI가 끝낸 상태로 넘긴다.

읽기 어렵거나 판단이 애매한 값은 추측하지 말고 요약 문장에 "(확인 필요)"로 남긴다.

## 요약 JSON 항목 (고정)

| 항목 | 자료형 |
|---|---|
| 제목 | 문자열 |
| 생성일 | `"YYYY-MM-DD"` 문자열 또는 `null` |
| 요약 | 문자열 목록 (빈 목록은 `[]`) |
| 섹션 | 객체 목록 (빈 목록은 `[]`) |

`섹션`의 각 객체는 아래 두 형태 중 하나다. `유형` 값으로 구분한다.

**글 섹션** (md 요약용)

| 항목 | 자료형 |
|---|---|
| 유형 | `"글"` |
| 소제목 | 문자열 |
| 출처 | 문자열 (근거 문서의 ID·파일명, 예: `"RULE-01 / W04_01_학교지원금지침.md"`) |
| 내용 | 객체 목록 (빈 목록은 `[]`) |

`내용`의 각 객체는 **핵심 숫자·내용을 그 근거와 함께** 담는다. 임의 요약이 아니라
원문에서 가져온 숫자·조건을 근거 문구와 함께 남긴다.

| 항목 | 자료형 |
|---|---|
| 항목 | 문자열 (무엇에 대한 값·규칙인지) |
| 값 | 문자열 (핵심 숫자 또는 핵심 내용. 예: `"1인 4,000원 이내"`, `"180명"`) |
| 근거 | 문자열 (원문 조항·문장 근거. 예: `"제2조: 식음료는 확정 참가자용 1인 4,000원 이내"`) |

**표 섹션** (csv 핵심용)

| 항목 | 자료형 |
|---|---|
| 유형 | `"표"` |
| 소제목 | 문자열 |
| 출처 | 문자열 (근거 CSV·문서, 예: `"회계내역.csv"`) |
| 열 | 문자열 목록 (표 헤더, 1개 이상) |
| 행 | 목록의 목록 (각 행은 문자열 목록, 길이가 `열`과 같아야 함) |

항목 이름·개수·자료형을 매번 동일하게 유지한다.
`출처`는 어느 문서·CSV에서 온 값인지 추적할 수 있도록 반드시 채운다(비우지 않는다).

## 실행 절차

1. 대상 md·csv 파일을 위 규칙대로 읽어 요약 JSON을 만든다.
2. 그 JSON을 파일이나 표준입력으로 검사·렌더·저장한다. Python 3.9 이상, 표준 라이브러리만 사용한다.

```bash
cd scripts
# 파일로 검사 후 저장
python3 render.py <입력.json> [출력.html]   # 출력 생략 시 report.html
# 표준입력으로 검사 후 저장
cat <입력.json> | python3 render.py - [출력.html]
```

- 검사 통과: 정해진 틀의 HTML을 저장하고 종료 코드 `0`.
- 검사 실패: 저장하지 않고 사유를 stderr로 출력, 종료 코드 `1`.

### 예시

`scripts/sample_valid.json`(정상)과 `scripts/sample_invalid.json`(오류)로 확인할 수 있다.

```bash
python3 render.py sample_valid.json out.html    # → "저장 완료: out.html"
python3 render.py sample_invalid.json out.html  # → 저장 안 함, 위반 사유 출력
```

입력 JSON 예:

```json
{
  "제목": "가을 교류회 준비 현황",
  "생성일": "2026-09-23",
  "요약": ["신청 12명 중 참가 10명, 불참 2명.", "간식은 총 8개, 생수 10병."],
  "섹션": [
    {
      "유형": "글",
      "소제목": "규칙 요약",
      "출처": "RULE-01 / 행사안내.md",
      "내용": [
        {"항목": "정원", "값": "12명", "근거": "제3조: 정원은 12명을 넘지 않는다"},
        {"항목": "간식 미응답 처리", "값": "확인 대상으로 남김", "근거": "제5조: 빈칸은 임의로 정하지 않는다"}
      ]
    },
    {
      "유형": "표",
      "소제목": "간식 주문",
      "출처": "참가신청.csv",
      "열": ["메뉴", "수량"],
      "행": [["샌드위치", "4"], ["주먹밥", "4"]]
    }
  ]
}
```
